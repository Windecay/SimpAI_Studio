P-H3-Image generates still images and edits with up to eight ordered images. The canvas is Picture 1 when present, followed by the references. With no image, it generates from the prompt. Default resolution is 2048 x 2048; 2912 x 2912 is also available. Mask editing is disabled.

Write a specific English description or edit instruction, or use the prompt assistant. PE is optional: choose an installed PE model in the model panel, or None to disable it. A prompt already applied by the assistant is not expanded again. Name references as <Picture 1>, <Picture 2> and so on, and quote visible lettering exactly in its original language. Preserve the source identity and all content outside the requested change.

Comfy Kitchen attention is the default. Enable Sparse Attention Acceleration in Advanced Parameters to use SLA with 10% retention. Image quality with SLA needs separate comparison.

This preset reuses the H3 hybrid model with P-H3 LoRA at strength 1, a dedicated INT8 text encoder and image VAE. Sampling uses Euler, the fixed eight-step schedule and shifts of 1/1. The hybrid combination needs visual comparison against the official FL2VA combination; official speed and memory measurements do not describe this preset.
