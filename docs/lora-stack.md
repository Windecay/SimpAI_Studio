# 扩展 LoRA 堆

## 使用规则

- 原有十槽继续保存预设和手动选择。扩展堆是独立列表，不占用、不移动、不填充旧槽位，没有固定条数限制；实际可用数量仍受内存、显存和模型兼容性限制。
- `<lora:名称:权重>` 标签全部使用堆。名称沿用已有解析规则，支持完整文件名、相对目录和可识别的文件名主体；支持小数、负权重。标签从送给文本编码器的提示词中移除，原有换行保留。
- 普通工作流使用 `main`。万相高低噪工作流使用 `high` / `low`，每个手动条目可选择高噪、低噪或两者。标签使用独立的 `lora_stack_target` 设置；双分支不能使用 `auto`，提交时会提示选择范围。
- 同一分支内，手动堆条目优先于同模型标签。有效旧槽位也优先于所在模型链上的同模型标签；不会因为高噪链已使用某个 LoRA，就删除低噪链的标签。同名重复标签只保留首次，手动堆中的显式重复项按顺序保留。
- 禁用项和模型/CLIP 权重均为零的条目不加载。CLIP 默认权重为零；非零 CLIP 权重要求节点已连接 CLIP，并把 CLIP 输出连接到需要使用它的编码器。
- 没有专用堆节点的自定义工作流使用有效堆条目或标签时明确报错，不转入旧槽、不静默忽略。Fooocus 等非 Comfy 后端不执行堆或标签，现有手动十槽仍保留。

## 界面与状态

主界面模型面板和画布模型配置共用基础编辑器：添加、删除、上移、下移、启用、模型文件名、模型权重、CLIP 权重、作用范围及标签作用范围。主界面的标签列表仅供预览，来源仍为提示词；画布标签在节点生成时解析，不读取主界面提示词。

可见文本读取 `state.__lang` 对应的前端语言状态，支持中英文，仅适配 Gradio 6。当前只实现基础交互，布局和交互细节后续调整。

`lora_stack` 和 `lora_stack_target` 在主界面、画布 classic/scene、预设保存、参数方案、复制参数及历史再生成中独立传递。外部 `simpleai_base` 归一化字段表由 Studio 和画布入口分别登记，不要求修改已安装的包。

历史快照额外保存提交时解析的 `lora_stack_prompt`，用于把标签恢复到提示词；它不属于手动堆字段，每次提交根据当前提示词重新生成，删除标签不会遗留上次的条目。

## 前后端协议

持久参数示例：

```json
{
  "lora_stack": [
    {
      "enabled": true,
      "model": "folder/example.safetensors",
      "strength_model": 0.8,
      "strength_clip": 0.0,
      "target": "high"
    }
  ],
  "lora_stack_target": "both"
}
```

`lora_stack` 接受数组、JSON 字符串或 `{"version":1,"items":[...]}`。合法范围为 `auto`、`main`、`high`、`low`、`both`。前端手动输入使用相对模型文件名；只有提示词标签执行文件名主体匹配。

专用节点 `SimpAILoraStack` 位于 `comfy/custom_nodes/SimpAINodes/SimpAILoraStack.py`：

- 必需输入：`model: MODEL`、`stack_json: STRING`、`branch: main/high/low`。
- 可选输入：`clip: CLIP`；输出：`MODEL, CLIP`。
- `stack_json` 格式为 `{"version":1,"items":[...]}`；提交映射将条目的 `target` 解析为节点的实际分支。
- 节点内部按列表顺序调用现有 LoRA loader，不展开图，不生成节点，不修改模型加载器内部实现。空堆直接返回原 MODEL/CLIP，不创建 loader；不增加常驻张量缓存。

`modules/lora_stack.py` 只修改现有堆节点的 `stack_json` 输入。原生 mapper 和 Python mapper 都经过此处理；运行时不创建、删除节点，不改动任何连接。一个分支的多个专用节点会接收同一分支的堆配置，适用于独立模型链；同一模型链通常只放一个专用堆节点。

## 模板迁移与部署

本次静态更新 91 个 API 模板，增加 102 个固定堆节点；10 个双噪声模板分别添加高噪/低噪节点，`sd15_aio_api.json` 的两条独立链各添加一个主模型堆。所有旧槽及其默认值保留，堆默认为空。

迁移只发生在模板文件中：原旧槽链末端的下游使用新的固定堆输出。比对 Git 原模板、移除新增节点并恢复这些固定连接后，91 个模板全部与原图相同，没有其他图参数改动。

部署需要同步前端、工作流模板和 `SimpAINodes`，然后重启 Studio/Comfy 后端。新版模板即使堆为空，也需要后端注册 `SimpAILoraStack`。这里的兼容范围是旧十槽数据和操作，不代表新版模板可以在缺少该节点的旧后端执行。

自定义工作流可继续只使用旧十槽；需要堆时，应在工作流编辑阶段添加专用节点，并选择正确分支。当前自带模板沿用原模型链的 MODEL-only 行为；需要 CLIP 权重的自定义工作流须显式连接 CLIP。
