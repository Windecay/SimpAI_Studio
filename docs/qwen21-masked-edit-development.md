# Qwen2.1 擦除与替换开发记录

## 1. 2026-10-04 可选区域图工作流

- 新增 `QwenEraser`（Qwen擦除）和 `QwenReplace`（Qwen替换），分别使用 `scene_qwen21_erase_api.json` 和 `scene_qwen21_replace_api.json`。源图必选，mask 可选；替换参考图也可选。默认不启用增强 LoRA，也不启用 PE 模型，沿用 Qwen2.1、Qwen3-VL、VAE 的魔搭优先下载源，不创建重复模型包。
- 现有 `SimpAIQwen21CanvasInpaint` 的 `noise_mask` 用于采样范围约束，没有作为视觉图片条件进入 `TextEncodeQwenImage21`。新节点将有效笔刷转换成独立黑白图片：原图为 `<image1>`，区域图为 `<image2>`，替换参考图存在时为 `<image3>`。无 mask 或全黑 mask 时不传区域图，替换参考图自动使用 `<image2>`。
- 官方模型 README 明确支持 circles、painted annotations、separate masks，官方编辑 Prompt 规则要求使用图像标签并说明各图角色。来源为 `https://github.com/QwenLM/Qwen-Image-2.1/blob/main/README.md` 与 `https://github.com/QwenLM/Qwen-Image-2.1/blob/main/prompt_rewrite/prompts/system_prompt_edit.txt`。用户提供的博客为 SPA，本次工具未读取到具体正文；未据此宣称黑白极性是模型的固定规范。
- 白色表示可编辑、黑色表示保留，是本流程显式写入 Prompt 的约定。绿色笔刷按 RGB 最大值提取，非零范围转为可见黑白图；原灰度保留给采样和输出合成，避免改变软边权重。区域图尺寸必须与源图一致，不将区域图解释为外观或输出背景。
- 没有 mask 时使用文字定位目标，不构造假蒙版；没有 mask 且没有指令时返回错误。擦除有 mask 时可以省略文字。替换需要替换描述或参考图，避免空指令任意生成目标。
- 继续使用固定节点的采样 mask 和最终合成，输出尺寸采用当前预置的 32px 量化设置。源图按相同规则缩放到输出尺寸后直接参与 RGB/RGBA 合成，保留 mask 外的源图通道。RGB 原图仍输出 RGB，RGBA 原图的范围外透明度不采用模型生成值；不改变普通 Qwen2.1-Edit 既有透明通道语义。
- 新流程实际模型路径为模型/LoRA stack → `ModelAttentionBackend("comfy kitchen attention")` → `QwenImage21Cache` → `KSampler`。现有 Edit、Outpaint、Pose、Gaussian 已具备该路径，本次只增加自动覆盖全部 Qwen2.1 预置的检查。
- 预置可见名称使用既有 `state.__lang` 本地化方式提供中文和英文，仅使用 Gradio 6。画布擦除、替换的默认值仍是 Eraser、Swap+；自然语言风格编辑不变，待实际生成效果验收后再更换默认值。
