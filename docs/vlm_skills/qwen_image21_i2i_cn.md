# Qwen Image 2.1 PE 图像编辑提示词技能

当 `Qwen2.1-Edit` 有一张或多张输入图片时使用这份技能。内容来自共享的
`image-prompt-i2i` skill，并已按 SimpAI 的提示词 action 约定整理。

## 源图和参考图角色

- 写涉及画面的事实前先查看用户提供的图片，不能根据文件名或没有查看的
  参考图猜测细节。
- 只有一张图时，在提示词中自然指向这张图；单图编辑不要添加图片标签。
- 有多张图时，按上传顺序使用 `<image1>`、`<image2>` 等标签，并说明每张
  图的角色：画布、身份、服装、物体、材质、风格或用户指定的其他来源。
- 除非用户明确要求用参考主体重新构图，否则画布图提供构图。不能默认第一
  张图就是画布，要根据用户要求判断。
- 不要编造缺失的图片、蒙版、视频、音频或参考图角色。

## 只修改用户要求的内容

- 直接从用户要求的操作开始，并让修改后的属性清楚可见。
- 用户没有要求改变的内容都要保留：身份、主体数量、姿势、物体设计、配饰、
  构图、透视、光线、色彩关系、媒介、背景和可读文字。
- 用一条清楚的保留要求概括未修改内容，不要把源图全部外观重新描写一遍，
  过度重述会增加漂移。
- 区分“修改现有图片”和“用参考主体创作新场景”。后者可以重新设计场景，
  但仍要保留用户要求的身份或物体细节。
- 不要自行增加清理、美化、风格变化、裁剪、留白、缩放、变形或其他操作。

## 语言和画面文字

- 描述性文字跟随用户请求语言：中文请求写中文，英文请求写英文，其他语言
  默认写英文。
- 画面内文字按以下顺序决定：用户给出的原文或目标语言、源图中已有文字的
  主要语言、用户请求语言。
- 除非用户明确要求双语结果，画面内文字保持单一语言。每段确定要显示的
  文字都用英文直双引号括起。
- 品牌、人名或可见标签只有在用户要求时才翻译。

## 比例和输出边界

- 判断输出应跟随哪张画布图，或采用用户明确指定的比例。扩图和新构图可能
  需要新的比例。
- 不要把像素尺寸、分辨率标签、`wh_ratio` 或 `ratio_follow` 写入最终提示词。
  这些值由 SimpAI 的结构化控件管理。
- Canvas Agent 请求中，把最终指令放入运行时 action 的 `prompt` 字段。不要
  输出共享 skill 的三字段 JSON，运行时 action JSON 优先。
- 只返回一段完整提示词，不要解释、Markdown 围栏、模型参数或内部规划。

## 返回前检查

检查操作、修改区域、保留内容、图片角色、引号文字和构图选择都已明确；不
得编造事实，所有输入图片必须按要求顺序引用。
