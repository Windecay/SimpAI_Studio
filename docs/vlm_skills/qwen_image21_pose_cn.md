# Qwen Image 2.1 姿态与相机视图迁移

用于 QwenPose 的标准和 Turbo 主题。查看实际提供的两张图。此预置迁移 Pose
Studio 导出图中的姿态和相机视图，包括用户在编辑器里直接调整、没有另外用文字
说明的景别与构图变化。

## 图片角色

- `<image 1>` 提供目标姿态和相机视图：身体与头部朝向、可见肢体与手势、机位、
  透视、景别、人物在画面中的大小与位置、身体的可见范围。
- `<image 2>` 提供人物身份、脸部、发型、自然身体比例、服装与配饰、原环境的
  外观、光照以及摄影或绘画风格。
- 保持这一顺序，不使用 H3 的 `<Picture N>` 标签。不复制灰模身份、灰色材质、
  白色背景或灰模的打光。

## 修改与保留

- 从替换姿态并匹配 `<image 1>` 相机视图开始。这里的姿态迁移包含导出图中
  已经确定的取景范围，不能只理解为调整关节。
- 图1是近景或上半身、图2是全身照时，明确采用图1的近景或上半身构图；不能
  要求保留原全身构图，不能把目标姿态缩回全身照，也不要求显示画面外的腿部或物品。
- 用简短要求保留人物和环境外观。背景的视角和可见范围允许随新构图变化，
  衣物褶皱、手持或搭在手臂上的物品随动作调整，也可以移出画面。
- 不自行增加“保留原机位、原构图、原人物大小、所有物品位置或所有可见物体”
  等限制。视图发生变化时，不使用“其他细节完全不变”一类整体限制。
- 用户明确约束优先，例如明确要求保留原机位、只调整肢体时按该要求处理。
  没有这种限制时，图1中可见的构图就是迁移目标；两图视图相同时，不另加视角变化。
- 只描述看得到的差异，不编造明显歪头、表情、精确焦距与角度或不可见肢体。
  保持提示词简洁，不逐项重述原图中的全部物品。

## 输出

最终提示词使用用户请求的语言，只输出一段正文；不要解释、JSON、Markdown
围栏、像素尺寸或额外模型参数。界面指引按 `__lang` 选择语言。Canvas action
把最终正文写入 `prompt`。检查保留要求是否与目标姿态和构图相冲突。

近景参考示例：
将 <image 2> 中女性的姿态替换为 <image 1> 的姿态，同时采用图1的机位、
上半身取景、人物大小与位置，以及可见的头部和肩部朝向。保留图2的人物身份、
服装、原环境外观和摄影风格，背景随新视角调整。不复制灰模材质和白色背景。
