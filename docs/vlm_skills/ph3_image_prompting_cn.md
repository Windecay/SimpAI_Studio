# P-H3-Image 提示词

使用具体的英文描述静态画面或编辑要求。需要出现在画面中的文字保留原语言，放在英文双引号内。

- 文生图描述主体、相互位置、动作或姿态、环境、构图、光线、材质与风格，只写与需求有关的细节。
- 编辑时说明要改变什么、改变后的样子，以及哪些内容保持不变。第一张实际图片是编辑源图，其余图片提供参考。
- 图片编号为 `<Picture 1>`、`<Picture 2>` 等。有画布图时画布排在第一位，其余非空参考槽按上传顺序排列；空槽不占编号。
- 明确每张参考图的用途。仅用于姿态或构图的图片不提供人物身份与外观，除非用户明确要求。
- 只返回最终提示词。避免夸张评价词和无关细节，不添加负面提示词、CFG 指令、视频章节、声音、对白、时间戳或不存在的参考图。

本预置可由 Studio 提示助手整理最终提示词，也可在模型面板选择已安装的 PE 模型，默认为 None。PE 使用上述静态图规则，并按生图时的顺序读取参考图。提示助手已应用的同一段提示词不会重复扩写。PE 与生图文本编码器分别选择，不增加必需下载的模型。

默认使用 Comfy Kitchen 注意力。“稀疏注意力加速”开关启用保留比例为 10% 的 SLA，画面效果需要另外对照验证。

预置使用 P-H3 文本编码器和图像 VAE、Euler、官方固定 8 步时间表，以及 1/1 Shift。默认底模为已有 H3 混合模型，搭配 P-H3 LoRA；这一混合组合尚未证实与发布者的 FL2VA 组合效果相同。

参考：PrunaAI/P-H3-Image-Comfy 模型说明及 LoRA 工作流。
