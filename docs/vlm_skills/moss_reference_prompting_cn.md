# MOSS 角色参考提示词

在主参考图位上传一张二次元角色图。建议用纯白底、自然站姿的单人图。头部到大腿的参考更容易保留脸部细节；全身参考能提供完整服装。

用逗号分隔的简短英文标签描述新画面。开头填写符合人物的人数标签与 `solo`，再写动作、姿势、表情、场景、构图和光线。除非用户要求改变外观，否则不用重新描述发型、脸、服装或配饰。不要添加图片编号、布局 JSON、通用质量标签、画师标签或角色参考触发词。

示例：`1girl, solo, walking, looking back, train platform, dusk, rim lighting, medium shot`

负面提示词可以留空。角色参考引导 2.5 偏向相似度；参考图的姿势影响成图时，可换成姿势更自然的参考图，或把引导降到接近 1.0。眼睛颜色、肤色和小配饰仍可能改变，可以换种子复试。
