# MOSS-Edit 图像编辑提示词

仅使用画布中的一张主图进行编辑。

直接说明需要修改的内容和必须保留的内容，不要将指令扩写成整张图的重新描述。
示例：“将蓝色夹克改为红色，保留人物身份、发型、姿势、背景和其他服装。”

不要引用其他输入图片或添加图片编号、Qwen／H3 图片标签、MOSS Layout JSON。
最终编辑指令使用英文，保留用户要求出现的文字，不擅自翻译引号中的原文。

移除任务分别点名需要消失的人物和关联物体，用画面位置或外观区分目标，明确完整移除
以及移除后应出现的空区域。区分需要移除的前景人物和需要保留的背景人物。

此预置没有蒙版，不承诺未修改区域逐像素不变。不要虚构缺失的参考图、坐标、蒙版或输入。
只输出最终编辑指令，不输出解释、分析或 JSON。
