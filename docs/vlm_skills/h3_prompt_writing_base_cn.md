# H3 基础模式专用规则

适用于 `T2VA`、`I2VA`、`FL2VA` 和 `L2VA`。实际模式由编译器指定，只执行当前模式的规则，不要把其他模式的图片对齐方式写进提示词。

## 输出结构

只输出以下三个字段，顺序固定：

```text
integrated_multimodal_description:

overall_soundscape:

non_diegetic_music:
```

`T2VA` 不写图片对齐前缀。`I2VA`、`FL2VA`、`L2VA` 在三个字段前各写一行对齐说明，并空一行：

- `I2VA`：`<Picture 1>` 在 `0.00` 秒完整对齐，画面从这张首帧继续发展。
- `FL2VA`：`<Picture 1>` 在 `0.00` 秒对齐，`<Picture 2>` 在目标时长对齐；重点写两帧之间连续、可见的变化。
- `L2VA`：`<Picture 1>` 在目标时长对齐，是末帧；开场状态由模型根据请求推断，动作逐渐到达这张图片。

## 各模式写法

- `T2VA`：从文字建立完整视听时间线，不添加任何图片 token 或图片对齐说明。
- `I2VA`：把 `<Picture 1>` 当作首帧事实。首个动作从 `0.00` 秒的画面状态自然延续，不要把首帧写成中途出现的参考图。
- `FL2VA`：把两张图片当作首尾约束。说明主体、姿态、环境、光线和镜头如何从首帧连续变化到末帧，不能只分别描述两张静态图片，也不要凭空跳到末帧。
- `L2VA`：把 `<Picture 1>` 当作末帧事实。明确开场状态、变化过程和到达末帧的动作，不要把这张图放在 `0.00` 秒，也不要把它写成首帧。

首尾帧之间没有明确要求时，优先使用一个连续镜头；只有用户明确要求剪辑、转场或场景切换时才增加镜头。镜头变化要写出类型、幅度和速度，例如 `Push In`、`Pan Left`、`Tracking Shot`、`Static Shot` 或 `POV`。

## 时间线与声音

- `integrated_multimodal_description` 从 `[Shot 1]` 开始。镜头按时间递增，时间范围不能超过目标时长，最后一个镜头必须到达目标时长。
- 每个镜头依次写可见动作和主体状态，再写 `Camera:`、`Dialogue and visible text:`、`Synchronized sound:`。
- 说话或歌唱的人物使用稳定的 `(S1)`、`(S2)` 编号。只有真实说出的词句放在 `<d>[Language] ...</d>` 中；没有对白写 `无`。
- 画面文字使用英文双引号包裹，并保留用户提供的原文。环境声、脚步、碰撞和非语言人声属于同步声音。
- `overall_soundscape` 只写画面内可听见的环境声、动作声和对白相关声音；`non_diegetic_music` 只写观众听见但画面内没有声源的背景音乐，没有音乐写 `N/A`。

基础模式只允许当前模式支持的图片 token：`T2VA` 不使用图片，`I2VA` 和 `L2VA` 只使用 `<Picture 1>`，`FL2VA` 只使用 `<Picture 1>` 和 `<Picture 2>`。不要写 `<Video N>` 或 `<Audio N>`，也不要新增、翻译或改编号。
